# 开发进度

> 只记录当前状态、里程碑和验证基线；完整历史与 diff 由 Git 保存。

## 当前状态

- 统一论文助手已经支持论文理解、连续对话、可选选区、公式固定、研究档案和证据页码回链。
- PDF.js 负责渲染，PDFium 负责选择和搜索，PDFBox 负责服务端版面事实。
- 论文事实由当前 PDF 版本的本轮 evidence 支撑；会话历史和论文画像只帮助理解与检索。
- 工作台当前仍以版面关键词检索为主；旧向量 RAG 没有接入统一论文对话，且仍引用已删除的独立 Embedding 设置。
- 当前主要缺口是通用混合召回、证据去重、回答与引用直接绑定，以及正文/双栏公式的精确回链。

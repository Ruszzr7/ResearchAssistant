# 开发进度

> 只记录当前状态、里程碑和验证基线；完整历史与 diff 由 Git 保存。

## 当前状态

- 统一论文助手已经支持论文理解、连续对话、可选选区、公式固定、研究档案和证据页码回链。
- PDF.js 负责渲染，PDFium 负责选择和搜索，PDFBox 负责服务端版面事实。
- 论文事实由当前 PDF 版本的本轮 evidence 支撑；会话历史和论文画像只帮助理解与检索。
- 工作台使用轻量查询计划、版面多路召回、倒数排名融合、相对裁剪、证据去重和同栏邻域扩展。
- 回答使用带事实类型和短引文的 `answerBlocks`；文字引用由 PDFium 二次定位，公式引用使用独立目标框。
- Embedding、Qdrant 和 LLM 重排链路已退役；旧 Skill 改用 MySQL 本地文本分片，不增加外部模型调用。

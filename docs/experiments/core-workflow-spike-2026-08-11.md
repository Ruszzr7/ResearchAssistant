# 核心工作流小范围验证（2026-08-11）

## 范围

本轮只验证两条核心假设，不替换正式业务链路，不迁移数据库，不重建全部论文制品。

1. 基于本地 PDF 字符几何，能否区分定理结论公式、证明步骤和正文公式引用。
2. PDF 操作命令前置路由后，当前选区高亮能否绕过检索与 LLM。
3. 向相同 LLM 提供完整正确的来源页后，回答能否恢复稳定。
4. 跨行文本能否生成精确 quads，并按规范化锚点去重。

## 验证一：公式实体与定理关系

样本：论文 188，第 6-7 页。

结果：

| 结构 | 原型识别 |
|---|---|
| Theorem 1 结论 | Equation (21) |
| Theorem 1 证明步骤 | Equation (22), (23) |
| Theorem 2 结论 | Equation (31) |
| Theorem 2 证明步骤 | Equation (32), (33), (34) |
| 正文 `in (34).` | Equation Mention，不是公式本体 |

公式 (21)、(31)、(34) 已使用字符几何生成独立公式框。整页可视化检查中，公式框未跨栏，未落到下方证明正文；`in (34).` 被作为独立引用标记。

结论：**PASS**。现有 PDF 的底层字符位置足以支撑方案，无需通过 LLM 猜测公式坐标。

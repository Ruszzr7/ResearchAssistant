# 证据 Skill 当前验收口径

本文件只记录当前生产协议和可重复回归结果；实现细节以 `skills/paper-evidence/SKILL.md`、
`docs/paper-evidence-skill-design.md` 和后端工具契约为准。

## 当前协议

- Agent 从最终答案需要成立的独立事实拆分 1～4 条证据需求（Evidence Need），每条使用稳定且唯一的 `id` 和中立 `objective`；首次有效检索后冻结 Need ID 集合。
- Need 的 `query` 用论文术语、变量、指标或公式编号；`keywords` 只用于首次无结果时的受限放宽；
  `targets` 用于返回后的对象核对；已知来源通过 `sourceObjectIds` 直接读取。
- 工具执行确定性检索、去重、来源读取和必要的局部视觉返回。结果只提供词面覆盖与调用进展，
  不判断语义充分性，也不证明论文没有更多内容。
- Agent 必须阅读返回的原文后判断答案是否已获得足够支持。只有具体缺口仍未解决时，才沿用同一 Need ID、保持 `objective`、填写 `refinementReason` 并改变检索条件再次调用。重复请求、补检索无新增来源、已停止 Need、新建 ID 绕过停止，或连续两次输入校验失败时均不再执行该方向的底层检索。
- 最终答案必须通过 `submit_answer` 提交；服务器只接受本轮真实读取且能支持对应答案块的来源 ID。

说明：工具名、JSON 字段、状态枚举、来源 ID、论文原始术语和 LaTeX 属于协议或数据，保留原样；所有发送给模型的自然语言说明、提示和错误文案均使用中文。

## 通过标准

| 维度 | 当前门槛 |
|---|---|
| Need 合同 | 1～4 条、ID/objective 唯一且非空、至少一种检索锚点；无效参数结构化失败 |
| 来源边界 | 返回来源属于当前论文版本，locator 页码和矩形有效 |
| 证据充分性 | 正向确定性需求至少命中一条直接来源；无依据问题不得编造引用或数值 |
| 返回规模 | 工具最多返回 6 条来源、8,000 字符内容和 16 KiB JSON |
| 本地耗时 | 四篇确定性样本的证据检索 p95 不超过 1.5 秒 |
| 终态安全 | 工具失败、模型超时和迟到终态不能伪造引用或覆盖已确定终态 |

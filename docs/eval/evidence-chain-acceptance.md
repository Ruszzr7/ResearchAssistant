# 证据检索链路临时验收口径

本文件只服务于当前重构验收；测试集扩充后可替换或删除。评测分开统计本地证据 Skill 与真实 Agent，避免把模型供应商时延误判成检索性能。

## 通过标准

| 维度 | 当前门槛 |
|---|---|
| 工具轮次 | 由 Agent 自主决定；应用层不设固定工具轮次流程上限。评测记录实际工具调用、重复需求和 `TOOL_ROUND_LIMIT`，但不为临时达标强制截断正常的不同需求 |
| 失败安全 | `TOOL_ROUND_LIMIT`、证据工具参数/执行失败和迟到终态覆盖均为 0；供应商真正超时时返回明确安全失败 |
| 本地耗时 | 单批证据检索不超过 1.5 秒，四篇样本报告 p95 |
| 端到端耗时 | 正常完成不超过 90 秒；90 秒是覆盖单次 60 秒模型请求的最终安全边界，不代表允许模型无限等待或重复检索 |
| 返回边界 | 最多 4 个检索需求、6 条来源、8,000 字符内容和 16 KiB JSON；查询最长 400 字符 |
| 证据充分性 | 每个正向检索需求至少返回 1 条来源；四篇确定性样本 Direct Recall@4 = 100% |
| 证据有用性 | 最终提交证据必须包含测试要求的直接原文与正确页码，不能只返回相关图注或主题相近内容 |
| 返回完整性 | 最终提交的 `sourceObjectId` 必须属于本轮唯一真实证据批次；来源必须存在于当前版本目录且 locator 页码、矩形有效 |
| 无依据安全 | 不支持的问题不得生成论文引用、页码、公式号或精确数值；可以明确说明论文未提供依据 |

## 2026-08-28 当前结果

- 确定性四篇集：15/15 Direct Recall@4，MRR 0.700，178/178 locator 有效，检索 p95 125 ms，所有响应小于 16 KiB。新增三个中文 Agent 风格困难查询均直接命中目标原文。
- 真实 Agent 修复后定向复测：论文 190“短码长—低错误率”与论文 191“91.48%”均通过，分别约 21.1 秒和 20.9 秒；每题 1 次真实检索，最终证据来自首批返回。
- 修复前六例基线中，所有本地证据调用均低于 0.4 秒、真实检索均为 1 次、工具失败为 0；失败来自两次直接证据选错和一次供应商慢响应。前两项已按上述定向复测修复。
- Agent 默认运行预算由 180 秒收紧为 50 秒；配合 5 秒扫描和轮询余量，供应商卡住时在 60 秒用户门槛内返回安全超时状态，不会继续等待或提交未完成证据。
- 最新超时复测中，供应商在首个模型调用阶段无响应，运行于 54.4 秒返回 `FAILED / 模型响应超时，请稍后重试`；工具调用为 0、证据为 0，证明超时不会伪造或提交半成品。该用例仍计为端到端可用性失败，不能算正常回答通过。

## 2026-08-29 超时修复后的当前结果

- 原完整 10 例在 8 轮保险线下曾因重复模型往返撞到 50 秒 Run deadline；将能力调用保险收敛为 2 轮后，最终完整集 10/10 均进入正常终态，P50/P95 为 26.2/36.3 秒，最慢样本 56.5 秒，未出现 `RUN_TIMEOUT` 或 `FAILED`。
- 四篇论文的最终证据集共 6 个请求全部正常结束，端到端约 8.1–28.2 秒；本地证据调用最大 298ms，响应最大 6,162 bytes，证据工具调用均无失败。
- 严格通过率为 4/6：论文 184 的失败是测试词面未命中，论文 191 的失败是测试要求 `maxEvidence=0` 与 Agent 主动取证行为冲突。完整 10 例其余失败还包括一条二分查找词面、一条公式术语词面和页面操作期望，不应混入性能指标。
- 运行时修复已增加迟到回答回归：Run 终态先于助手消息写入；超时线程抢先完成时，迟到结果不再写入助手消息，也不再触发 `FAILED -> COMPLETED` 状态冲突。后端全量 519 项执行、0 失败、0 错误、9 项跳过。

## 2026-08-29 Agent 化方案执行后的当前验收

- 应用层已移除固定工具轮次上限；模型/工具数量仅作为诊断快照，Agent 可自主再次读取不同或未解决的需求。证据 Skill 的单次调用仍以 `needs[]` 批量检索，并对未覆盖需求最多执行一次 fallback，避免 Skill 内部无限搜索。
- 后端全量回归为 521 项执行、0 失败、0 错误、9 项跳过；证据 schema、fallback、Skill 描述、页面操作可信目标和超时竞态均有定向回归。
- 真实 RSMA 10 例全部进入预期终态，0 `FAILED`、0 `RUN_TIMEOUT`，最大耗时 58.5 秒；四篇论文 6 例全部 `COMPLETED`，0 证据工具失败，证据本地调用最大约 131ms。说明当前“工具执行失败/运行时超时”问题未在本批次复现。
- 当前未通过项不合并为一个分数：RSMA 中有回答词面测试假阴性、选区无效页面操作，以及方法/P0 问题的重复证据调用；四篇集中的唯一严格失败为论文 190 公平性问题，9 次证据调用、约 60.5 秒。该重复调用是后续待讨论的 Agent 收敛问题，不通过再加硬轮次补丁解决。
- 页面操作仍采用单动作票据；本轮没有扩展 `actions[]`，避免为测试改变现有客户端回执与幂等协议。测试材料仍是构建期辅助材料，可按用户要求清除；未提交 Git。
